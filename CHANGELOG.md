# Changelog

## 0.1.0

- Add Go support: `@code` and `$` markers in `//` and `/* */` comments

## 0.0.3

- Add Preserve Nested Comments feature
- Improve code quality and readability

## 0.0.2

- Remove support for fenced code blocks; only `@code` and `$` markers are
	supported.
- Restrict syntax highlighting to the current file language.
- Add implicit JavaScript, Rust, and Python comment grammars.
- Restore the README preview image reference.

## 0.0.1

- Initial release.
